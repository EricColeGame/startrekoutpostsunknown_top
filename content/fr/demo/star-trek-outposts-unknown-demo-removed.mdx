## Pourquoi la démo de Star Trek Outposts Unknown a-t-elle été supprimée ?

La fiche Steam ne contient aucune note publique expliquant ce changement ; la réponse la plus exacte est donc que le build d'essai a simplement été retiré maintenant que le jeu est en vente. C'est une pratique courante pour les démos sur les boutiques. Une fois un titre commercialisé, les éditeurs retirent généralement l'échantillon afin que chaque nouveau visiteur arrive sur la même page produit, le même build et le même ensemble de captures d'écran.

Plusieurs raisons reviennent régulièrement dans l'industrie, et elles s'appliquent aussi ici :

- **Consolidation du lancement.** Une page, un build, un seul ensemble de configurations système à prendre en charge.
- **Dérive entre les builds.** Une démo figée des mois avant la sortie peut se comporter très différemment de la version commerciale, ce qui génère des rapports de bugs déroutants.
- **Compatibilité des sauvegardes.** Les sauvegardes de démo sont rarement transférables vers les versions commerciales, et les joueurs n'aiment pas perdre leur progression.
- **Promotion limitée dans le temps.** Beaucoup de démos sont explicitement temporaires et expirent à une date fixée.
- **Capacité de support.** Un petit studio comme Magic Fuel Games doit concentrer son assurance qualité sur la version que les gens ont réellement payée.

Si vous voulez vérifier le statut vous-même, la [page Steam de Star Trek: Outposts Unknown](https://store.steampowered.com/app/3469910/Star_Trek_Outposts_Unknown/) est la source faisant autorité — si une démo revient, le bouton de téléchargement réapparaîtra d'abord là.
